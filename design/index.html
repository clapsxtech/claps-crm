clClapsLearn ERP · Design system v2

A calmer operating system for a tutoring business

The whole ERP, rethought from first principles: one navigation model grouped around jobs (Growth, People, Teaching, Money), one component library with every state specified, and motion that explains each change. It’s plain HTML and CSS with a small runtime, so you can open any file straight in a browser.

Jobs, not tables

Twelve flat links become four groups that match how the team actually works. Pages a role can’t use are hidden, and you can preview any role from the account menu.

Keyboard-first

⌘K searches students, leads and receipts, and jumps to any page. [ collapses the sidebar and D switches density.

Optimistic + undo

Attendance, pipeline moves and archiving apply instantly and offer undo, so day-to-day edits don’t need a confirmation dialog.
