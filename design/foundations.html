Foundations

Tokens are the single source of truth. Components use only semantic tokens, so theme and density can change globally without editing a single component.

Motion

Motion should explain what changed. Entering elements decelerate and exiting ones accelerate. Only toggles and confirmations get the spring. All durations drop to 0 under prefers-reduced-motion.
